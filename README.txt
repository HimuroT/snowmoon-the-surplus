THE SURPLUS
84-second unofficial animated adaptation of Snowmoon, Chapter 5.
Public source edition prepared 13 October 2026.

A conversation between rivals on a visit to Freetown turns their reasoning
for a shared break into something more personal. This short uses original
vector animation, English captions and procedural music/sound. There is no
voiced dialogue. Dialogue, staging, costumes and incidental visual details
are adaptation choices; this is not an official or endorsed adaptation.

REBUILD
Requirements: Python 3, numpy, scipy, Pillow, Inkscape, FFmpeg and DejaVu Sans.
The tested versions are in source/dependencies.json. The scripts were run on
Linux; the contact-sheet helper currently uses the standard Linux DejaVu Sans
font path. Other platforms may need that font path adjusted.

From this project folder:
  bash source/render_film.sh

This regenerates every SVG/PNG frame, all float32 audio stems, the 84-second
1080p/24fps H.264/AAC video, a representative still, objective checks and a
complete source ZIP. Outputs are The_Surplus_84s.mp4 and
The_Surplus_84s_still.png. Allow several gigabytes of space for intermediate PNGs.
No earlier proof folder or external asset is required. To regenerate just
the original 48 kHz stereo float32 audio:
  python3 source/synthesize_audio.py

To regenerate the compact independent ZIPs after the full build:
  python3 source/package_delivery.py

OPTIONAL AUDIO DOWNLOADS
Full-length 24-bit FLAC copies of the mix, ambience, effects and music are
supplied separately for convenience. They are not time-split and need no
joining. The precise float32 masters can always be regenerated by the source.
See DELIVERY_README.txt for the measured format-conversion difference.

VERIFICATION AND LIMITS
The supplied film is exactly 84.000 seconds, 1920x1080 at 24 fps, with 2,016
video frames and stereo 48 kHz AAC. All 17 caption boundaries and source
frames were checked; the entire file decodes successfully. The first/last
frames intentionally fade to the same dark color. This is stylized 2.5D
limited animation, with graphic reflections and phrase-timed mouths.

Realtime synchronized playback and perceptual listening have not been
interactively verified. Measured integrated loudness is about -31 LUFS;
phone/speaker audibility and the naturalness of footsteps and pauses still
need a listening check. These limitations are not resolved merely by
successful numerical decoding. Competition eligibility has not been assessed.

The release retains the reviewed picture and audio. Only distribution names,
container metadata and documentation were prepared for public use. Rebuilding
with different tool versions may change encoded bytes without changing content.
