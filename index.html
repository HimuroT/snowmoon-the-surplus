THE PIPELINE

From paths to a small story.

Python defines the character rigs, poses, timing and SVG frames. Inkscape renders the images. NumPy and SciPy generate the sound from fixed seeds; FFmpeg assembles the film.

REBUILD LOCALLY

No generation service required.

Install Python, NumPy, SciPy, Pillow, Inkscape, FFmpeg and DejaVu Sans, then follow the included workflow. Allow several gigabytes for intermediate frames.

bash source/render_film.sh

Production notes & verification

Created with OpenAI assistance. The source includes original geometry, animation logic, procedural audio synthesis, selected creative instruction excerpts and a reconstructed production brief. The excerpts are not a complete session transcript.

The 84-second file contains 2,016 frames and stereo 48 kHz AAC audio. Full-file decoding, frame sources and caption boundaries were checked. Realtime synchronized playback and perceptual listening have not been interactively verified. Measured integrated loudness is approximately −31 LUFS, so audibility will vary with the listening setup.

The FLAC downloads losslessly encode a 24-bit conversion of the float32 audio masters. Exact float32 masters can be regenerated from the source. The measured conversion difference and tested tool versions are included.

The public MP4 uses the original audiovisual streams; only the container title/comment were updated for release. Original source fonts and commodity tools are not bundled or relicensed.
